# Live check — M4.3 часть B (карта регионов; при `region_side = 0` поведение не должно измениться)

Состояние: **не выполнялось владельцем**. Дефолт `region_side = 0` —
разбиения нет: весь мир остаётся регионом 0, тик идёт inline (пул простаивает),
поэтому критерий — вход и ходьба **как в M4.2/M4.3A**. Автоматически:
`cargo test --workspace` (сценарии `Transfer` а–д, канонический транскрипт,
плейбек журнала, транскрипт одинаков при K=0/1/4/8).

## Шаги (5 строк)

1. В `server.toml` поле `region_side` не задавать (или `region_side = 0`) —
   это и есть проверяемое поведение; запустить `tools\run-server.bat`, ждать
   `listening`, без `WARN`/`ERROR`.
2. Войти клиентом 26.3 на `localhost:25565` (view distance 8) — экран входа
   и 289 чанков приходят как раньше, без «дыр» и зависаний.
3. `F3`: пройти 30+ блоков вперёд/назад — координаты идут плавно, без
   скачков и откатов (тот же чек, что в M4.2).
4. В логе сервера не должно быть строк `tick woke late` при входе и ходьбе;
   если есть — записать `late_ms`, тик и число игроков.
5. Скриншот (мир + F3) и, если была строка `tick woke late`, её текст — в
   отчёт. Норма — сообщить «M4.3B ок»; иначе прислать лог и координаты.
