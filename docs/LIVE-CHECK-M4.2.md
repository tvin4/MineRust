# Live check — M4.2 (позиция игрока, разбор хода в тике)

Состояние: **не выполнялось владельцем**. Критерий §6 M4.2 — позиция F3
при ходьбе меняется **без скачков**. Автоматически проверено:
`cargo test --workspace` (декод видов, игнор до `TeleportAck`, применение
после ack, rotation не двигает, replay-детерминизм) и разовый e2e
(in-process сервер + ручной `parity::Client`, см. `PROGRESS.md` раунд 8).

Бот `parity` для этой проверки не подходит: он для всех режимов кроме
`Preload` требует от сервера spectator (`login game_mode 0; expected 3`),
а наш сервер отдаёт survival; `Preload` же не двигается.

## Шаги

1. Запустить сервер: `tools\run-server.bat` (или `cargo run -p server
   --release`). Ожидание в логе: `listening local=0.0.0.0:25565`, без
   `WARN`/`ERROR`.
2. В Minecraft **26.3** → Multiplayer → Add Server: `localhost:25565`;
   войти.
3. Включить координаты `F3`. Записать **x/y/z сразу после входа** (это
   точка входа — центр блока спавна).
4. Пройти 30+ блоков вперёд, затем постоять, затем пройти назад. Следить
   за координатами на F3: они должны расти/убывать **плавно**, без
   телепортов, откатов и «дрожания» (скачок назад мимо собственного пути
   — дефект применения хода).
5. Повернуться на месте (двигать мышь). Координаты x/y/z **не должны
   меняться** — поворот передаётся пакетом `move_player_rot` и позицию не
   трогает.
6. Скриншот (мир + F3) положить рядом с этим файлом или в
   `E:\MineRust-data\traces\`.
7. Открыть `logs\latest.log` клиента: строк `WARN`/`ERROR` про наш сервер
   быть не должно (записать, если есть).
8. Необязательно: задать `MINERUST_REPLAY=<путь>\replay.jsonl` перед
   запуском сервера; после ходьбы в файле должны появиться строки
   `"kind":"move"` с монотонными координатами (шаг хода), по одной (или
   несколько) на такт.

## Заметки

- Позиция принимается **без проверок** движения (осознанная дыра M4,
  `docs/DECISIONS.md`); до `TeleportAck` (первое подтверждение телепорта
  входа) ход игнорируется — это ожидаемо и мгновенно.
- `set_chunk_cache_center` при ходьбе сейчас не пересылается: окно чанков
  в M4.2 не двигается (перенос центра кэша — M4.4, стриминг). «Дыры» в
  новых чанках вдали от спавна — ожидаемы до M4.4, к M4.2 не относятся.
