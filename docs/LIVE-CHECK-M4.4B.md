## Шаги (8 строк)

1. В `server.toml` `world_dir` — рабочий шаблон (у владельца v2
   `E:\MineRust-data\world-template`); запустить `tools\run-server.bat`, ждать
   `listening` и `world warm-up finished: chunks ready to send N`.
2. Во время **входа** в логе (уровень `debug` для `net`) одна строка
   `chunk window selected` с `in_window=473`; в `info` — `chunk batch sent`
   (число порций и чанков); `WARN`/`ERROR` нет.
3. Войти клиентом **26.3** на `localhost:25565`; после входа пройти **30+
   блоков** в одну сторону (и немного по диагонали).
4. В логе ходьбы — строки `window move` с растущим `center_x`/`center_z` и
   полями `add`/`remove`/`queued`; на каждом переходе видно `add≈23`,
   `remove≈23` (по диагонали `37`). Не должно быть `not_cached`-строк в глубине
   мира (только у края шаблона — это норма: край не «дыра»).
5. `F3+G`: окно следует за игроком; **дыр внутри окна нет** (за краем по
   периметру мир может достраиваться — норма), края не «отваливаются» назад.
6. `F3`: координаты плавно, без скачков/откатов. Мгновенный разворот и бег
   назад через уже пройденный путь — тоже без дыр.
7. Смотреть период ходьбы на предмет `tick woke late` (единичный выброс при
   входе допустим — сборка джоина); записать `late_ms`, тик, число игроков.
8. Скриншот (мир + F3, желательно `F3+G`) — в отчёт. Норма — «M4.4B ок»;
   иначе прислать лог (`net=debug`), координаты, маршрут и скриншот.
